# Insights

The **Insights** tab is an analytics area for understanding how an agent is used. Most views support **24h**, **7d**, and **30d** windows plus a manual refresh, and each sub-tab has its own URL (for example `/agents/{owner}/{storeName}/insights/traffic`) so a specific view can be linked to directly.

## Sub-tabs

- **Pulse** summarizes active users, chats, messages, files added, vectors added, and top active users.
- **Contributors** shows message activity by user over time.
- **Traffic** tracks Agent page views, unique visitors, referrers, and top paths.
- **Word Cloud** aggregates common terms from the agent's messages. It is not period-scoped and includes a minimum-frequency filter.
- **Cost** charts token usage and estimated cost, including average cost per message and peak usage.
- **Stargazers** lists the users who starred the agent.
- **Watchers** lists the users who watch the agent.
- **Forks** lists the agents forked from this one.
