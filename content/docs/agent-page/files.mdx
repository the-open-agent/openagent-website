# Files

The **Files** tab shows the agent's knowledge base as a file tree — the same tree surfaced at the top of the [Overview](/docs/agent-page/overview) tab. Use it to inspect which documents back the agent before starting a conversation.

For how files are uploaded, embedded, and retrieved, see the [Knowledge Base → Files](/docs/knowledge-base/files) reference.
