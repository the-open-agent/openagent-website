# Resources

In the product UI, **Resources** sits alongside Files and Vectors as part of the knowledge-base area.

For most teams, the main workflow still starts with:

- [Files](/docs/knowledge-base/files) for document ingestion
- [Vectors](/docs/knowledge-base/vectors) for retrieval

Use Resources as the broader bucket for knowledge-related supporting objects shown in the admin UI.

<Callout type="info">
  If you're just getting started with RAG, you usually do not need to begin here. Start with [Add a Knowledge Base](/docs/add-a-knowledge-base), then come back as needed.
</Callout>
