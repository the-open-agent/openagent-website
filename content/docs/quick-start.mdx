# Quick Start

The goal of this guide is to reach the **"First Message"** milestone as quickly as possible. OpenAgent runs on port `14000` by default.

---

## 1. Deploy the Infrastructure

Choose the deployment method that fits your environment.

<Tabs items={['One-Line Install', 'Docker', 'Development']}>
<Tab value="One-Line Install">

**macOS / Linux / WSL**
```bash
curl -fsSL https://raw.githubusercontent.com/the-open-agent/openagent/master/scripts/install.sh | bash
```

**Windows (PowerShell)**
```powershell
irm https://raw.githubusercontent.com/the-open-agent/openagent/master/scripts/install.ps1 | iex
```

</Tab>
<Tab value="Docker">

```bash
docker run -d -p 14000:14000 --name openagent casbin/openagent
```

</Tab>
<Tab value="Development">

Requires Go 1.21+, Node.js 18+, and MySQL 8.0+.

```bash
git clone https://github.com/the-open-agent/openagent.git
cd openagent
go run main.go
# Separate terminal
cd web && yarn install && yarn start
```

</Tab>
</Tabs>

Once the server is running, navigate to **`http://localhost:14000`**.

---

## 2. Reach the First Message

Follow these atomic steps to initialize your first agent.

<Steps>
<Step>

### Configure a Provider
Navigate to **Providers → Add Provider**.
- **Category**: `Model`
- **Type**: `DeepSeek` (Recommended for cost) or `OpenAI`
- **API Key**: Enter your credentials.
- **Model (Sub Type)**: Select `deepseek-v4-flash` (Cost-efficient) or `gpt-5.5` (State-of-the-art).

<Callout type="warn">
  **Screenshot Placeholder:** The "Add Provider" form with Model category selected.
</Callout>

</Step>
<Step>

### Initialize an Agent (Store)
Navigate to **Stores → Add Store**.
- **Name**: `primary-assistant`
- **Model Provider**: Select the provider from Step 1.
- **System Prompt**: *"You are a professional research assistant."*

<Callout type="warn">
  **Screenshot Placeholder:** The "Add Store" form highlighting the Prompt and Model Provider fields.
</Callout>

</Step>
<Step>

### Validate with Chat
Open the **Chat** interface from the sidebar. Select your agent and send:
> "Hello OpenAgent, identify yourself."

<Callout type="warn">
  **Screenshot Placeholder:** The Chat UI showing a successful response.
</Callout>

**Milestone Reached:** You now have a functional, self-hosted orchestration engine.

</Step>
</Steps>

## 3. Activate Knowledge Retrieval (RAG)

Transition from a standard LLM to a **Knowledge Agent** by indexing your own data.

<Steps>
<Step>

### Add Embedding Intelligence
Add a provider under the **Embedding** category (Recommended: `text-embedding-005` for value or `qwen3-embedding-8b` for accuracy).

</Step>
<Step>

### Link Knowledge to Agent
Edit your Store and assign the **Embedding Provider**. Set **Knowledge Count** to `5` (Recommended for 2026 models) to define retrieval density.

</Step>
<Step>

### Ingest Documents
Go to **Files → Upload**, drop your PDFs/Markdown files, and assign them to the Store. Once the status reaches **Finished**, the agent is grounded in your data.

</Step>
</Steps>
