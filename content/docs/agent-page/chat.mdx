# Chat

The **Chat** tab embeds the full chat experience directly in the [Agent page](/docs/agent-page), so users can try the agent without navigating away. It behaves exactly like the standalone chat page — streaming responses, inline tool calls, attachments, and follow-up suggestions all work the same way.

For the full request lifecycle and chat features, see the [Chat reference](/docs/chat).
