# Settings

The **Settings** tab is visible only to the agent's owner. It embeds the full Store edit form inline, so the owner can configure every aspect of the agent — model, knowledge base, tools, prompt, voice, and publishing — without leaving the Agent page. Editing happens in place rather than redirecting to the standalone Store edit page, and the tab is deep-linkable at `/agents/{owner}/{storeName}/settings`.

For the complete field reference, see [Stores](/docs/basic/stores).
